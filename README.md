# Fahmida Love Letter ❤️

A mobile-first personal letter website made with Next.js.

## Run locally

If you previously installed dependencies from an older version, remove them first:

```bash
rm -rf node_modules package-lock.json
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Vercel

Push this folder to GitHub and import the repository into Vercel. No environment variables are required.

The photos are already inside `public/photos/`.
